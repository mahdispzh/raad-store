## Routes

PUBLIC

PROTECTED
GET /api/protected/discounts
POST /api/protected/discounts

GET /api/protected/discounts/[discountId]
PUT /api/protected/discounts/[discountId]
DELETE /api/protected/discounts/[discountId]

public / protected
